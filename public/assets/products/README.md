# Imagenes de productos

Guarda aqui las fotos de producto en formato PNG o JPG.

Regla:

`public/assets/products/<id-del-producto>.jpg`

La app intenta cargar primero JPG y, si no existe, busca PNG.

Tamano recomendado:

- Horizontal.
- 1200 x 800 px o similar.
- Producto claro, bien iluminado.
- Fondo limpio: hielo, charola, vitrina o mesa clara.
- Evitar fotos oscuras, borrosas, con texto, precios o logos encima.
